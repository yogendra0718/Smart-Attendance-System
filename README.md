# Smart Attendance System (Face Recognition)

This project uses Python and OpenCV to mark attendance using face recognition.

## Features
- Face detection using webcam
- Automatic attendance marking
- Stores data in CSV file

## Technologies Used
- Python
- OpenCV
- face_recognition
- NumPy
- Pandas

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Add images in 'images' folder

3. Run:
   python main.py
